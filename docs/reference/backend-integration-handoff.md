Help/browser acceptance remain delegated; this record does not infer visual

core handler/root/SDK disposition and explicit browser/legacy exclusions. The
[workspace compatibility freeze](../releases/backend-integration-contract.md#workspace-mutation-compatibility-freeze--2026-10-12)

accepts both argument forms; actual compiled calls against native `1212ea3b`
match persisted responses, scope refusals and restart behavior. The explicit
workspace-ID helpers remain available.

verified exact envelopes. Saved Chat contracts preserve revisions, complete
content/detail, drafts/settings/attachments and scoped deletion. Video's new
`ingested_image` type is published with explicit safe-failure/qualification
boundaries. These contracts allow frontend integration without waiting for every
external merchant, Supplier or Provider to activate. Implementation readiness
and actual positive upstream execution are separately recorded in each linked
checkpoint; no empty success substitutes for an unsupported business operation.

offline dependency set. Handler extraction is current at 156 operations; root
entrypoints resolve 139 registered paths with those generated methods. Build and
schema checks establish publication consistency, not business acceptance.

A separately served native HTTP artifact check reads all 17 content routes and
30 local page/resource targets, including the published handler JSON. Responses,
local resource availability and the handler spec match the retained build.
The backend-business page links the fixed status board, compatibility freeze,
Chat checkpoint, current report matrix and video input contract.

These checks do not exercise rendered navigation, search controls, desktop or
narrow-width presentation, embedded Help, or the frontend's complete business
journeys. Those belong to S13 and remain delegated to frontend ownership. No
browser result is invented when actual rendered observation is unavailable.
