# Niu staging UX consistency review · 2026-11-12

Observed on staging after deployment [42977456010](https://github.com/niu-io/cloud/actions/runs/42977456010), cloud composition `49d7f83`, pinned core `7ebe8ef90` and website `953847d`. The local branch contains additional changes and is a separate evidence source. The scope is review only. Beads parent: `niu-287`. The earlier acceptance of #122 applies to its recorded revision.

## Ownership and product rules

| User goal | Owner and intended surface | Observed conflict and disposition |
| --- | --- | --- |
| Discover a model I can use, hand it to my agent, and inspect results | Workspace owns available models, keys, logs, usage and safety policy. Public catalog owns public discovery. | Keep one clear workspace route per task. Split public discovery from authenticated availability at the route boundary. A workspace selector changes context across surfaces. |
| Try or compare a model | Workspace owns access and saved material. Generations owns composer, history, run and asset workflows. | Retain Generations, place history and library in a coherent workspace journey, and keep a durable destination for a shared run. |
| Connect an external agent and recover access | Agent initiates, user sees and authorizes scope, agent verifies, user can revoke. | Retain one recognizable onboarding action and distinguish opening instructions, approving a connection, and inspecting issued access. |
| Understand spend and fund usage | Workspace owns attributable usage and statements. Organization owns shared credits and funding. Account owns personal preferences. | Keep usage, statements and funding linked. Make the scope visible before acting. Separate personal preferences from organization administration in navigation language. |
| Operate supply or administer the instance | Platform administration owns supplier costs and pricing. Provider portal owns a Provider's own records. | Preserve separate permission and data boundaries. Treat workspace Routing and Evaluations as separately qualified product surfaces. |

## Review criteria

Niu's navigation hierarchy and scope rules define the canonical workspace design. The usability review applies consistency, match with user language, visibility of state, and error recovery to the concrete observations above. OpenRouter's public catalog is a comparison for global discovery and repeated pricing/context facts, while Niu's workspace availability has a distinct ownership requirement. Contrast and reflow need measurement before asserting WCAG conformance.
