Both modes reject streaming, tools, structured-output requests and Embeddings before inference; streaming observation and external detectors remain unimplemented.

Observation stores immutable, workspace-scoped `clear`, `matched` or `indeterminate` metadata in a separate table. Request Guardrail diagnosis returns it separately from enforcement outcomes. Metadata contains no matched text, original content, credentials or Supplier costs. Oversized or opaque output remains deliverable under observation and records indeterminate coverage. Observation persistence failure is reported in server diagnostics without becoming an implicit blocking rule. Transport/body failures remain upstream errors.
