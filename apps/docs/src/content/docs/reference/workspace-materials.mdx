---
title: Workspace materials
description: Durable local material APIs and their generation integration boundary.
---

Workspace materials are saved in encrypted backend storage. Member APIs provide
upload, list, metadata, rename, delete and authenticated download for images,
video and audio. Saving a material does not grant Provider ingestion, model
inspection approval or generation permission.

Read the [material library contract](https://github.com/niu-io/niu/blob/main/docs/reference/workspace-material-library.md)
for SDK methods, limits, revisions, deletion and explicit pending integration.
The [implemented operations](/docs/reference/handler-operations/) contain the
request/response schemas and authorization/error contracts. Actual file formats, scoped SDK persistence, deletion, byte/object capacity
and nonempty key rotation have independent acceptance records. Saved-image
request parsing and safe unsupported-channel refusal are verified; qualified
fresh-inspection generation remains unverified. This page does not claim a
complete Seedance workflow.
