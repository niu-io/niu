---
title: Performance and cost
description: Niu's product goals and how the complete path will be measured.
---

Niu optimizes two outcomes: performance and cost. Security defines the conditions a configuration must satisfy before it can be compared.

Performance includes request admission, authentication, route selection, policy execution, provider calls, streaming, and settlement overhead. Report p50 and tail latency, time to first token, throughput, failure rate, memory, and CPU.

Cost includes provider spend, retry exposure, inference overhead, deployment resources, and operational effort. Customer charges and provider liabilities are separate accounting dimensions. Budget enforcement requires durable admission and recovery, not a response-time estimate alone.

Compare full configurations with the same protocols, tasks, providers, capabilities, and safety conditions. Record source versions, images, workloads, environment, raw results, and known limits.
