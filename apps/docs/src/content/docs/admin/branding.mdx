<div data-lang="en">

Open **Admin → Branding & theme**. Deployment defaults are saved in the backend and differ from a member's own light/dark preference.

## Branding

In the **Branding** tab, set the display name and upload a logo or favicon. The current form accepts:

| Asset | Format | Limits |
| --- | --- | --- |
| Logo | PNG | Up to 1024 × 512 pixels and 256 KB |
| Favicon | Square PNG | Up to 256 × 256 pixels and 32 KB |

Use **Use default** to remove an uploaded override. The display name is shown on sign-in screens and browser tabs. Niu is the default English product name.

## Theme

In the **Theme** tab, choose the default appearance and set supported light/dark color overrides. Colors use the validated six-digit hexadecimal format. Leave an override empty to use its default. Arbitrary CSS or executable branding content is not accepted.

Use **Preview** to inspect the draft, then save and confirm the persisted configuration. A preview alone does not publish settings. Review both light and dark appearance before changing a deployment default; a member's explicit preference remains separate.

Configuration changes are administrator-only and revisioned. Reload on a conflicting revision. See [branding writes](/docs/api/rest/savebranding/) and [branding reads](/docs/api/rest/getbranding/) for the exact public contract, and [audit logs](/docs/reference/platform-audit/) for recorded changes.

</div>

<div data-lang="zh" data-title-zh="品牌与主题">

打开**管理 → 品牌与主题**（**Admin → Branding & theme**）。部署环境的默认设置保存在后端，与成员个人的浅色/深色外观偏好相互独立。

## 品牌设置

在**品牌**（**Branding**）标签页中，设置显示名称并上传 Logo 或网站图标（Favicon）。当前表单支持以下规格：

| 资产 | 格式 | 限制 |
| --- | --- | --- |
| Logo | PNG | 最大 1024 × 512 像素，且不超过 256 KB |
| Favicon | 正方形 PNG | 最大 256 × 256 像素，且不超过 32 KB |

使用**恢复默认**（**Use default**）可移除已上传的自定义覆盖项。显示名称会展示在登录界面和浏览器标签页上。Niu 是默认的英文产品名称（中文品牌名称为 Niu 牛元 / 牛元）。

## 主题设置

在**主题**（**Theme**）标签页中，选择默认外观并设置受支持的浅色/深色颜色覆盖值。颜色采用经过校验的六位十六进制格式。将覆盖项留空即可使用其默认值。系统不接受任意 CSS 或可执行的品牌内容。

使用**预览**（**Preview**）检查草稿效果，然后保存并确认已持久化的配置。仅执行预览不会发布设置。在更改部署环境的默认设置之前，请同时检查浅色和深色外观效果；成员显式设置的个人外观偏好仍将保持独立。

配置变更仅限管理员操作，并受修订版本控制。遇到修订版本冲突时请重新加载页面。有关确切的公开接口契约，请参阅[保存品牌配置](/docs/api/rest/savebranding/)与[读取品牌配置](/docs/api/rest/getbranding/)；有关已记录的配置变更，请参阅[审计日志](/docs/reference/platform-audit/)。

</div>
