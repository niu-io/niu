## Performance benchmark

The [published Niu / New API / LiteLLM Proxy benchmark](/docs/guides/gateway-benchmarks/) covers throughput and tail latency, native Anthropic requests, SSE streaming, simulated multi-turn coding sessions, and memory. It records Niu v0.2.4, New API 45fbb14 and LiteLLM Proxy v1.104.0 on Apple M4 with PostgreSQL 17.11 and a deterministic zero-delay mock upstream. OpenRouter was not included.

These historical synthetic measurements are unverified for the current release and do not establish current end-to-end performance or production capacity. Read the [configuration, full measurement tables and reproduction steps](https://github.com/niu-io/niu/blob/main/docs/reference/gateway-performance-benchmark.md) alongside the results; the gateways used different database logging configurations and PostgreSQL synchronous commit was disabled.

## Which approach fits?

Choose **OpenRouter** if you want hosted catalog access without operating a gateway. Evaluate **New API** if its documented upstream integrations and instance-management workflows match your requirements. Evaluate **Niu** if you want to operate its workspace, Provider, and request-accounting workflows and its current supported scope meets your needs.

No gateway makes every model cheaper or interchangeable. Compare the actual model, endpoint, supported inputs, customer price, and observed behavior for your workload.

## 性能基准测试

[已发布的 Niu / New API / LiteLLM Proxy 基准测试](/docs/guides/gateway-benchmarks/)涵盖了吞吐量与长尾延迟、原生 Anthropic 请求、SSE 流式传输、模拟多轮编码会话以及内存占用。该测试记录了 Niu v0.2.4、New API 45fbb14 和 LiteLLM Proxy v1.104.0 在搭载 PostgreSQL 17.11 与确定性零延迟模拟上游的 Apple M4 环境下的表现。测试未包含 OpenRouter。

这些历史合成测量数据尚未针对当前版本进行重新验证，不代表当前的端到端性能或生产容量。请结合测试结果一并阅读[配置说明、完整测量表格与复现步骤](https://github.com/niu-io/niu/blob/main/docs/reference/gateway-performance-benchmark.md)；各网关在测试中使用了不同的数据库日志记录配置，且禁用了 PostgreSQL 同步提交（synchronous commit）。

## 哪种方案更适合？

如果您希望直接访问托管模型目录而无需自行运维网关，请选择 **OpenRouter**。如果 **New API** 文档中记载的上游集成与实例管理工作流符合您的需求，请评估 **New API**。如果您希望自主运营工作空间、模型供应商与请求核算工作流，且 **Niu** 当前支持的能力范围满足您的需求，请评估 **Niu**。

没有任何网关能让所有模型变得更便宜或完全可互换。请针对您的实际工作负载，综合对比具体的模型、端点、支持的输入、客户价格以及实际观测到的运行表现。
