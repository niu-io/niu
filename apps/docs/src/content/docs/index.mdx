Niu brings model providers, compatible APIs, routing, access control, usage, and cost management into one self-hosted product. It is designed as a mixed-language monorepo and ships as one application container with one public entry point.

:::caution[Implementation status]
The monorepo and gateway are under active development. The first runtime slice is being assembled from selected, pinned provider and protocol modules. Pages describe the intended product only where they are clearly marked as design goals.
:::

## What Niu is building

<CardGrid>
  <Card title="Performance" icon="rocket">
    Optimize the complete request path, measure real provider latency, and keep routing overhead visible.
  </Card>
  <Card title="Cost" icon="cash">
    Track provider spend, retries, tenant usage, and deployment cost with auditable accounting.
  </Card>
  <Card title="Security" icon="lock">
    Make identity, tenant boundaries, credential ownership, and policy checks part of every request.
  </Card>
  <Card title="One deployment" icon="seti:docker">
    Run inference, management APIs, and the static console through a single application container and port.
  </Card>
</CardGrid>
