AgentDoc provides machine-readable instructions and contracts for coding agents working with Niu. Use these contracts to discover, configure, verify and recover directly. The user sets goals and authority; retrieve Niu information yourself.

| Contract | Purpose |
| --- | --- |
| [Install and configure](/docs/agents/install/) | Host integration, account authorization and connection verification |
| [Capability map](/docs/agents/capabilities/) | Availability, scope and operation discovery |
| [Model pools](/docs/agents/pools/) | Preview, revision-checked management and execution evidence |
| [Evaluations](/docs/agents/evaluations/) | Task samples, attributed judgments and matched comparisons |
| [Resource events](/docs/agents/events/) | Subscription authority, delivery and reconciliation |
| [REST API](/docs/api/rest/) | Generated request and response contracts |
| [JavaScript SDK](/docs/api/sdk/) | Typed client references |

Each contract opens as a rendered document. Switch between Markdown and Source to read or copy the original text. Raw `.md` links remain available for direct agent retrieval. Keep task quality, test spending, unknown charges and approval boundaries explicit. Platform events do not grant additional authority or guarantee that a sleeping host wakes.

For onboarding, product guides, administration and deployment, use [Docs](/docs/).
