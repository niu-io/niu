Use these contracts to discover, configure, verify and recover directly. The user sets goals and authority; retrieve Niu information yourself.

| Contract | Purpose |
| --- | --- |
| [Install and configure](/docs/install.md) | Host integration, account authorization and connection verification |
| [Capability map](/docs/agents.md) | Availability, scope and operation discovery |
| [Model pools](/docs/pools.md) | Preview, revision-checked management and execution evidence |
| [Evaluations](/docs/evaluations.md) | Task samples, attributed judgments and matched comparisons |
| [Resource events](/docs/events.md) | Subscription authority, delivery and reconciliation |
| [REST API](/docs/api/rest/) | Generated request and response contracts |
| [JavaScript SDK](/docs/api/sdk/) | Typed client references |

The `.md` links are plain Markdown sources intended for direct agent retrieval. Embedded Help displays them as copyable source code. Keep task quality, test spending, unknown charges and approval boundaries explicit. Platform events do not grant additional authority or guarantee that a sleeping host wakes.

For product orientation and the short onboarding workflow, use [For Human](/docs/).
