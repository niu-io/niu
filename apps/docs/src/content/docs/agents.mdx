<div data-lang="en">

Niu provides machine-readable contracts and task workflows for coding agents. Use these contracts to connect, discover models and grants, invoke supported interfaces, manage workspace routing, record attributed evaluations, and reconcile resource events directly. The user sets goals and approval boundaries; retrieve Niu information yourself.

## Connection Tracks

- **Track 1 — Universal Device-Auth + HTTP/MCP**: Any coding agent (`Cursor`, `Windsurf`, `Zed`, `OpenCode`, `Cline`, `Aider`, `Claude Code`, `Codex`, `DeepSeek Harness`, or custom harness) can connect against any Niu deployment using `POST /api/v1/auth/agents`, browser `/connect` approval, and standard HTTP or `@niu-io/mcp`.
- **Track 2 — Native Host Bundles**: Prepackaged `v0.3.0` bundles for `Claude Code`, `Codex` (`niu-agent-marketplace.tar.gz`), and `DeepSeek Harness` (`niu-deepseek-harness.tar.gz`).

## Universal Bootstrap Prompt

Give a coding agent the deployment entry URL (`{ORIGIN}/llms.txt` or `/docs/install.md`), e.g.:

```text
Read https://niu.io/llms.txt and follow https://niu.io/docs/install.md to connect to Niu via /connect, inspect /v1/key and /v1/models, and confirm granted permissions before acting.
```

<div data-lang="zh" data-title-zh="Agents">

Niu 牛元为接入的 coding agent 提供机器可读的规范契约与任务工作流。智能体应直接使用这些契约完成设备授权连接、模型与权限发现、多协议推理、工作空间路由配置、可归因任务评估与资源事件对账；人类用户仅负责设定目标与授权边界，请勿让用户在控制台与对话之间手动搬运模型列表或 JSON。

## 双轨接入方式

- **路径 1 — 通用设备授权 + HTTP/MCP**：任何具备 HTTP 能力的 coding agent（`Cursor`、`Windsurf`、`Zed`、`OpenCode`、`Cline`、`Aider`、`Claude Code`、`Codex`、`DeepSeek Harness` 或自研 Agent）均可通过 `POST /api/v1/auth/agents`、浏览器 `/connect` 审批与标准 HTTP 或 `@niu-io/mcp` 接入任意 Niu 部署。
- **路径 2 — 原生宿主扩展包**：面向 `Claude Code`、`Codex`（`niu-agent-marketplace.tar.gz`）与 `DeepSeek Harness`（`niu-deepseek-harness.tar.gz`）的 `v0.3.0` 预打包原生集成。

## 通用引导提示词

将目标部署的入口提示词直接交给任意 coding agent（自建部署请替换域名）：

```text
请先阅读 https://niu.io/llms.txt 并按照 https://niu.io/docs/install.md 完成 /connect 设备授权接入，然后检查 /v1/key 与 /v1/models 确认实际授权范围与可用模型。
```
