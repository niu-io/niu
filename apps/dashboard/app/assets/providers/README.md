# Provider marks

Selected SVGs from [Lobe Icons](https://github.com/lobehub/lobe-icons), pinned to commit `329f378cbd1a88f45b60cd096b9111ce16f3ea39`, from `packages/static-svg/icons/`. SVGs are unmodified; see LICENSE for upstream attribution. Brand names and marks belong to their respective owners and are used for identification.

Only these static assets are reused; no upstream runtime or repository history is included. These marks identify model families or known endpoint hosts; they do not imply API adapter support or endorsement. Unknown providers use a neutral fallback. Assets are bundled locally, with no third-party requests at runtime.

Provider profile presets also use the pinned OpenRouter, New API, Azure, AWS, and Google Cloud marks. Their canonical upstream URLs are stored in the existing `logo_url` field; the dashboard resolves recognized presets to bundled assets. Custom URLs retain their original behavior.

## Official Provider marks

The small FastRouter and BabelArk PNG marks identify the corresponding integration. Their trademarks and original artwork remain the property of the respective Providers. Retrieved 2026-11-01; favicon containers converted to PNG without redrawing the artwork.

- `fastrouter.png`: https://fastrouter.wecitytech.com/favicon.ico (official service; its public `/api/status` identifies FastRouter and links its documentation).
- `babelark.png`: https://api.babelark.ai/babelark-square.ico (official API origin supplied by the product owner; `/api/status` identifies Babelark).

These files are distinct from the MIT-licensed Lobe Icons assets described above; no license over a third-party trademark is implied.
